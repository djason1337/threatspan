Quick Start

  1. Open and add at least a few API keys (free tiers cover most use).
  2. Paste any IP / domain / URL / hash in the search bar & press Enter.
  3. Watch the right pane for the live risk gauge & verdict.
  4. Expand any module card for full structured findings.
  5. Use the download export menu to push results into your SIEM / TIP / ticket.

Investigation Playbooks

The chips under the search bar pre-select a curated set of modules for a specific scenario.

Full Profile — every applicable module. Most thorough, highest API usage.
Quick Triage — only 4 reputation modules. ~64% fewer API calls than Full for IPs. Use when the alert queue is on fire.
Phishing Triage — URL/domain modules + urlscan screenshot + WHOIS age check + 7-step phishing checklist.
Ransomware IOC — VT + MalwareBazaar + ThreatFox + OTX + Shodan, with an IR checklist.
C2 Infrastructure — Shodan + GreyNoise + WHOIS + DNS recon for command-and-control hunts.

Each playbook also pre-fills the analyst notes with a checklist tailored to that workflow.

Bulk IOC Extraction

Click queue or press ⌘B. Paste an entire SIEM alert, email body, or log line — every IPv4, domain, URL, MD5, SHA1, SHA256 (including defanged forms like 8[.]8[.]8[.]8, hxxps://) is auto-extracted. Pick which to investigate; each becomes its own history entry.

MITRE ATT&CK

When AlienVault OTX returns pulses tagged with ATT&CK technique IDs (T1071, T1486, etc.), they appear as clickable chips on the OTX card. Use the ATT&CK Navigator layer export to drop the techniques into the MITRE ATT&CK Navigator for visual heat-mapping.

CISA KEV + CVE Enrichment

When Shodan returns CVEs on a host, ThreatSpan automatically:

  • Cross-references against the CISA KEV catalog — actively-exploited CVEs get a red badge.
  • Pulls CVSS v3.1 scores + severity from NIST NVD.
  • Links each CVE to its NVD detail page.
  • Bumps the Shodan risk score for ransomware-associated KEVs.

URL Parameters

Wire ThreatSpan into any tool that opens URLs (macOS Shortcuts, Raycast, Alfred, browser bookmarklets):

http://localhost:3000/?ioc=8.8.8.8&playbook=quick

Auto-fills the search bar, applies the playbook, and starts the investigation.

Privacy & Security

Server only listens on 127.0.0.1 — not reachable from your network. API keys live in localStorage and only travel to their respective providers (proxied via the local server to bypass CORS). No telemetry, no cloud, no phone-home.
